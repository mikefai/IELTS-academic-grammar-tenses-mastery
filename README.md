# IELTS Grammar Mastery Suite (B2 CEFR Level)

Comprehensive IELTS Academic English grammar preparation repository containing:
1. **IELTS Tenses Master Handbook**: 13 modules, formulas (active & passive), examiner insights, common candidate pitfalls, and 390+ authentic IELTS academic example sentences (10+ per usage).
2. **100-Question MCQ Mock Exam**: Full-length 100-question multiple-choice exam matching B2 difficulty with timed Exam Mode (60 min), Practice Mode, and an IELTS Band Estimator (4.0–9.0).
3. **Master Offline Guide**: Publication-ready Markdown reference (`IELTS_Tenses_Master_Guide.md`).

## 🛠️ How to Host on GitHub Pages

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Choose branch `main` (or `master`) and directory `/ (root)`. Click **Save**.
5. Your live site will be accessible at:
   ```
   https://<your-username>.github.io/<repository-name>/
   ```
